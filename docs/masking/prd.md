# Python 数据脱敏产品需求规范 (PRD)

> **组件归属**：`services/privacy-engine-python`
> **版本标定**：v3.0

---

## 1. 业务目标

落实《个人信息保护法》与等保三级关于个人信息去标识化和静态脱敏的技术规范，在开发、测试、运维诊断与外部数据导出中全面遮蔽个人敏感标识。

---

## 2. 核心功能与合规指标

| 场景 | 对应字段 | 脱敏策略 | 合规验收基准 |
|---|---|---|---|
| 自然人身份识别 | 居民身份证 | 保留前6后4 | GB/T 35273-2020 附录 B |
| 通信与联系方式 | 手机号码 | 保留前3后4 | 工信部个人信息保护规范 |
| 交易与结算账号 | 银行卡/信用卡 | 保留前4后4 | JR/T 0197-2020 金融规范 |
| 身份去标识化 | 用户唯一主键 | HMAC-SM3 加密打码 | 国密 SM3 算法规范 |
| 跨域联合统计 | 关键数值 | 顺序保持/保形加密 (FPE) | 保证不可反向破译 |
