# Python 动态分类分级产品需求规范 (PRD)

> **组件归属**：`services/privacy-engine-python`
> **版本标定**：v3.0

---

## 1. 业务目标与标准对齐

全面满足《GB/T 43697-2024 数据安全技术 数据分类分级规则》、《JR/T 0197-2020 金融数据安全分级指南》以及地方健康医疗规范（如四川省 DB51、广东省规范）。

---

## 2. 关键能力要求

1. **多标准动态切换**：在单次请求中支持通过 `standard` 参数动态指定合规体系（如按金融 C1-C4 级别或医疗 L1-L5 级别输出），规则引擎自动映射标签。
2. **两阶段提交热重载**：规则文件修改在运行中毫秒级生效，若新 YAML 存在语法错误，必须自动回滚并保留原内存规则库。
3. **安全路径沙箱**：规则加载与验证路径强制受控在指定目录内，禁止 `..` 路径穿越注入。
4. **大模型熔断护栏**：外部大模型调用故障时平滑降级，确保核心分类可用性不中断。
