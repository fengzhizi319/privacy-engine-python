# Python 差分隐私（DP / LDP）产品需求规范 (PRD)

> **组件归属**：`services/privacy-engine-python`
> **版本标定**：v3.0

---

## 1. 业务目标与价值

在金融联合风控、跨机构医疗统计与用户行为分析中，数据使用者往往需要获取聚合统计结论（如平均年龄、总支出、患病率分布），但法律法规严格禁止直接暴露或反推个体微观数据。

**核心业务价值**：
1. **严格数学证明**：遵循 $(\epsilon, \delta)$-差分隐私数学定义，从信息论上证明攻击者利用任意先验辅助信息均无法可靠反推个体参与状态。
2. **预算生命周期闭环**：对租户或分析人员设定总预算上限，防止攻击者通过组合多次微小扰动查询进行差分重构（Reconstruction Attack）。
3. **高吞吐与向量化**：支持批处理与 Arrow IPC 流式加噪，保障百万级报表秒级出具。

---

## 2. 关键功能特性 (Functional Requirements)

- **FR-DP-01 多机制自适应**：支持纯 $\epsilon$-Laplace 机制与 $(\epsilon, \delta)$-Gaussian 机制。
- **FR-DP-02 数值自适应裁剪**：强制实施上下界截断，提供固定上下界（`lower_bound`/`upper_bound`）与分位数自适应裁剪（`adaptive_clip`）。
- **FR-DP-03 复合与流式聚合**：提供单遍累加器（`Accumulator`），在分布式或低内存环境下仅保留轻量状态完成带噪统计。
- **FR-DP-04 本地差分隐私闭环**：提供二值与离散多分类的端侧加噪（`perturb_*`）与服务端无偏估算（`estimate_*`）。
- **FR-DP-05 多后端预算记账**：支持进程内缓存、Redis 集群与 SQLite 持久化后端，保证分布式并发环境下的扣减原子性。
