# Python K-匿名与 L-多样性产品需求规范 (PRD)

> **组件归属**：`services/privacy-engine-python`
> **版本标定**：v3.0

---

## 1. 业务背景与目标

在大数据流动、医疗科研协作与联合建模场景中，原始业务数据必须在出域前进行脱敏与泛化处理。单一的掩码脱敏无法应对关联分析攻击（Linkage Attack），攻击者可通过外部公开选民登记表、社保清单与内部泛化数据的准标识符（QI）交叉碰撞识别真实身份。

**核心业务诉求**：
1. **防止跨域重识别**：落地 K-匿名规范，使攻击者从准标识符组合推断个体的先验概率上限为 $1/k$。
2. **防范同质性攻击**：在疾病、收入等核心高敏属性上强制实施 Distinct L-多样性，杜绝等价类内敏感取值单一性引发的隐私泄漏。
3. **保持下游可用性**：采用 Mondrian 局部自适应区间泛化，避免过度粗粒度抑制导致数据价值丧失。
4. **性能与高并发**：单节点支持千条级数据集在 10ms 内完成多维切分与等价类计算。

---

## 2. 功能性需求 (FR)

| 需求编号 | 需求项 | 说明 | 验收标准 |
|---|---|---|---|
| FR-KANO-01 | 多维 Mondrian 泛化 | 按最大跨度轴递归二分，各分区大小均 $\ge k$ | 输出等价类大小均 $\ge k$ |
| FR-KANO-02 | 退化小样本保护 | 数据集总记录数 $< k$ 时不抛错 | 整表作为一个等价类统一泛化输出 |
| FR-KANO-03 | 启发式单记录泛化 | 支持流式/单记录查表泛化（年龄、邮编等） | 自适应匹配层级输出 |
| FR-KANO-04 | Distinct L-多样性审计 | 事后统计等价类内敏感属性相异基数 | 准确标识不合规等价类及相异基数 |
| FR-KANO-05 | L-多样性感知切分 | 切分前评估子集敏感多样性，跌破 $l$ 拒绝切分 | 输出满足 $l$-diversity 约束 |
| FR-KANO-06 | Arrow 元数据扩展 | 导出附带隐私配置的 Arrow Table | Schema 元数据包含等价类数与 $k$ 值 |

---

## 3. 非功能性需求 (NFR)

- **确定性 (Determinism)**：相同输入在相同参数下必须产生字节级一致的泛化结果，等价类编号基于 QI 键自然排序。
- **内存安全**：限制单请求最大记录数为 5,000 条，最大准标识符数为 50，防止内存耗尽 (OOM)。
- **可观测性**：必须集成 Prometheus 指标埋点 `privacy_kano_operations_total` 与 `privacy_kano_duration_seconds`。
