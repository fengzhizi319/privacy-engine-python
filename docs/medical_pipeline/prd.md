# Python 医疗数据治理产品需求规范 (PRD)

> **组件归属**：`services/privacy-engine-python`
> **版本标定**：v3.0

---

## 1. 业务合规目标

对齐《四川省健康医疗大数据应用指南》与《广东省健康医疗数据安全分类分级管理技术规范》：
1. **L5 极高敏感数据零外泄**：HIV/艾滋病、重度精神疾病、遗传缺陷等信息，出域必须经过彻底不可逆抹平。
2. **L4 高度敏感数据受控出域**：性病、恶性肿瘤、重度脏器衰竭等病种，出域必须抽象为大类标识符。
3. **输出原子证明**：系统必须随响应返回 `guarantee_no_l4_l5_raw_data: true`，作为不可篡改审计凭据。
